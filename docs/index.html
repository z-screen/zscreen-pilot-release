Z-Screen - Pilot Release - April 2026

A small pilot that points to a much bigger way to discover drugs.

Z-Screen makes many new molecules, puts each one in front of living cells, and reads out what happened. These five preprints show the first version of the full loop: measure the response, learn which parts of the chemistry matter, predict new molecules, estimate how they may behave in other cell types, and connect each hit to a likely genetic pathway.

About this release

Most drug-discovery platforms force a tradeoff. You can screen a lot of compounds, or you can deeply understand a few. Z-Screen is built to do both in the same experiment. Each tiny well holds a small group of cells and one bead carrying one compound. The chip images the cells, reads their RNA, and keeps the chemistry attached to the biology.

This release is the first scientific case for that loop. It is still a pilot, but the signal is already broad enough to show why scale matters: every new well can make the map more useful for the next molecule. The data and reproduction scripts are public on Zenodo, and the papers are being shared before formal bioRxiv submission so the work can be challenged and improved. More on the platform →

The five preprints

Each preprint answers a simple discovery question.

The papers are organized like a discovery team's checklist: can we measure what a molecule did, can we learn from that measurement, can the learning survive new chemistry, can it transfer across cell types, and can it point us toward mechanism?

PAPER 01 - ActiveSeq
One well gives both the picture and the molecular readout.
The same tiny well is imaged and sequenced. That means a hit is not just "cells looked different"; it also comes with an RNA fingerprint that helps explain the response. In the control panel, combining image and RNA worked better than either readout alone.
Read the non-technical summary
PAPER 02 - Generative Chemistry
The screen becomes a design map, not just a list of hits.
Because every compound is built from known chemical pieces, Z-Screen can learn which pieces move which cell programs. In the best-sampled systems, that was enough to predict the RNA response of compounds the model had not seen.
Read the non-technical summary
PAPER 03 - Generalization Ladder
We ask whether the model is learning or just copying.
The paper uses a ladder of harder tests. In one system, the model still helped when the test compounds were built from chemical pieces withheld during training. In another, it clearly behaved more like gap-filling inside a dense library. That honesty matters.
Read the non-technical summary
PAPER 04 - Cross-Cell Transfer
Measure once, then estimate where else to look.
Running every compound in every cell type is expensive. This paper shows a first version of cross-cell projection: use paired data to learn how a chemical program in one cell type is likely to appear in another, then prioritize the wet-lab follow-up.
Read the non-technical summary
PAPER 05 - Causal Reasoning
A hit can come with a mechanism hypothesis on day one.
The RNA fingerprint of each compound is compared with public CRISPR atlases. That does not prove the target, but it turns an anonymous phenotypic hit into a ranked, testable hypothesis. One highlight: two unrelated paths converged on V-ATPase biology.
Read the non-technical summary
Independent validation

Signals that the map is seeing real biology.

The important question is whether this is just a clever analysis of one dataset. The release includes several checks: agreement with a public reference, a known positive control, chemistry that follows the logic of CRISPR combinations, and an independent rediscovery of the same biological pathway.

EXTERNAL REFERENCE
Z-Screen agrees with an outside RNA reference.
For compounds that also appear in LINCS L1000, the Z-Screen RNA signatures point in the same direction. The overlap is not huge, but every adequately covered matched comparison was positive without platform-specific tuning.
See the cross-platform test
INTERNAL LOGIC
The chemistry follows genetic logic.
A CRISPR double perturbation should look related to the two single perturbations that compose it. Z-Screen chemical signatures followed that pattern across the Norman CRISPR atlas and reproduced it in a second library across three cell lines.
See the combinatorial test
POSITIVE CONTROL
A known BRD4 drug points back to BRD4.
MZ1 is designed to degrade BRD4. When its Z-Screen signature was compared against a matched THP1 CRISPR panel, BRD4 came back as the top calibrated match. That is the kind of anchor this framework needs.
See the positive control
DISCOVERY EXAMPLE
Two separate paths point to V-ATPase biology.
BAY-293 produced a V-ATPase and vesicle-trafficking signature in A549. Separately, an unrelated ZEL028-2 chemistry in HEK293 surfaced ATP6V1A with independent subset support. Different chemistry, different cell context, same biological neighborhood.
See the cross-system rediscovery
Pilot scope

This is what showed up before scale.

The pilot is small relative to what the platform is built to run. That is the point. If a limited campaign can already produce reproducible cell responses, usable predictions, cross-cell transfer, and CRISPR-linked hypotheses, the natural next question is what happens when the same loop runs at full campaign scale.
