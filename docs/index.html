About this release

Z-Screen is a 50,000-well experimental format with a built-in mRNA sequencing workflow. Z-Screen profiles one-bead-one-compound combinatorial libraries by paired imaging and transcriptomics, at five to ten cells per well. Most discovery platforms make drugs OR profile them. Z-Screen does both, on the same platform, in the same week.

This release is the first formal scientific case for what the platform can do at pilot scale. Five preprints, one canonical dataset, every claim reproducible end-to-end from the code in the public analysis bundle. The dataset and reproduction scripts are deposited on Zenodo with a citable DOI; this is the pre-bioRxiv pilot release. More on the platform →

The five preprints

Each preprint answers one question discovery teams already ask.

Five drug-cell interaction questions: can we measure it? can we predict it? does it generalize? does it transfer? does it explain mechanism? Each paper stands on its own; together they describe a drug discovery paradign for the AI era.

PAPER 01 - ActiveSeq
We see what a compound does and understand why, at the same time.
Imaging plus transcriptomics in the same microwell across 20,222 wells. Same-well fusion improves recall on all 35 control compounds. Normalized for task difficulty, the pilot matches the strongest public multimodal benchmark at an order of magnitude fewer cells.
Read the non-technical summary
PAPER 02 - Generative Chemistry
Mapping chemical sub-structures to biology predicts the cell-state response of unseen compounds.
615,793 profiles across 12 libraries and 4 cell lines. Building-block models cut held-out prediction error by up to 33%. With zero platform-specific calibration, Z-Screen signatures agree with the LINCS L1000 public reference at median ρ = 0.490.
Read the non-technical summary
PAPER 03 - Generalization Ladder
Predictions hold up on new chemistry, not just close copies.
A five-rung benchmark separates interpolation from extrapolation. Under strict multi-axis holdout, the model beats chemistry-embedding nearest-neighbor retrieval on 90% of compounds at a +0.168 cosine margin. This tells us the model is learning chemistry from the biology it perturbed, not memorizing features.
Read the non-technical summary
PAPER 04 - Cross-Cell Transfer
Test in one cell type, predict the response in others.
A first practical tissue projection engine. By learning across landmark perturbations, chemical programs transfer across paired cell lines at cosine 0.66 to 0.86, against an identity baseline of 0.42 to 0.52. In-silico clinical trials become possible when learned effects on an accessible cell type can be projected to complex tissues.
Read the non-technical summary
PAPER 05 - Causal Reasoning
Every compound nominates its likely genetic target, automatically.
8,599 chemistries scanned against 8,603 genome-wide CRISPR knockouts. 1,276 chemistries return a calibrated mechanism hypothesis (q ≤ 0.05) across 1,714 distinct CRISPR programs. A generative chemical search engine over combinatorial genetic perturbation space, built from the screen itself.
Read the non-technical summary
Independent validation

Four signals from outside the pilot's own framing.

The hardest question for any new platform is whether the signal is real. We answer it with four checks that the platform did not get to define. A public reference atlas. Internal combinatorial logic the framework can't fake. A matched-cell positive control with a known answer. And an emergent discovery whose internal coherence rules out chance.

EXTERNAL REFERENCE
Z-Screen agrees with LINCS L1000.
Of 47 named Z-Screen control compounds, 14 are present in the LINCS L1000 public reference. Restricted to the 12,328-gene LINCS-visible universe with no platform-specific calibration, all 11 (compound, cell-line) pairs with adequate coverage produced positive Spearman correlation. Median ρ = 0.490; 5 compounds reach empirical p ≤ 0.048 against an unmatched-compound permutation null.
See the cross-platform test
INTERNAL LOGIC
Chemistry follows CRISPR combinatorial structure.
For all 131 paired CRISPR-activation perturbations in the Norman atlas, Z-Screen substructure-vs-double CRISPR-edit match scores correlate positively with the sum of substructure-vs-single CRISPR-edit scores (median Spearman ρ = 0.353; every double significant at p ≤ 0.05). The chemistry tracks the same combinatorial structure the genetic atlas was built to express.
See the combinatorial test
POSITIVE CONTROL
Same-cell control: MZ1 recovers BRD4.
MZ1 is a small-molecule PROTAC that degrades BRD4. Scanned against the matched-cell THP1 CRISPR panel, Z-Screen recovers BRD4 as the top calibrated match out of all available perturbations. Net z = 6.84, empirical q = 0.015.
See the positive control
DISCOVERY EXAMPLE
BAY-293 surfaces a coherent V-ATPase program.
BAY-293 is an SOS1 inhibitor. Beyond its primary target, the framework surfaces a V-ATPase and vesicular-trafficking CRISPR program at q = 0.003, with nine matching components reaching net z above 10. Top hit ZW10 lands at z = 11.86. This is true discovery that a target-based search would not have produced.
