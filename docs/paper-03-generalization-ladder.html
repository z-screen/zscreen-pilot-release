PAPER 03 - Generalization Ladder

How do we know the model is not just copying close cousins?

Drug-discovery ML can look impressive when the test molecules are very similar to training molecules. This paper builds a ladder of harder tests to separate useful prediction from near-neighbor lookup. The result is deliberately bounded: one system shows real held-chemistry extrapolation, another shows valuable gap-filling inside a dense library, and the hardest scaffold-hop test becomes the next experiment.

TL;DR

The paper asks a hard but simple question: when chemistry changes, does the model still help? In ZEL031 / THP1, it beat nearest-neighbor retrieval when key chemical building blocks were held out. In ZEL024 / HEK293, it mainly filled gaps inside a very dense library. The hardest cross-library scaffold shift is not solved yet; it is now clearly defined.

Why it matters

Investors hear a lot of claims that models can predict chemistry. The missing question is usually what kind of new chemistry. A new combination of familiar parts is not the same as a molecule built from parts the model has never seen. A new scaffold family is harder still.

This paper makes that distinction explicit. Every rung of the ladder has a simple nearest-neighbor baseline: what if we just copied the most similar measured molecule? A model only earns credit when it beats that baseline.

What we did

We built five tests. The easiest holds out new combinations of familiar building blocks. Harder rungs hold out individual building blocks, then multiple building-block positions, then whole chemical neighborhoods. The hardest asks whether a model trained on one library family can transfer to another in the same cell line.

At every rung, the model is compared with a nearest-neighbor baseline that copies the measured response of the closest training compound. That baseline is the guardrail against accidental hype.

What we found

The ladder separates useful claims from inflated ones.

FINDING 01

One system shows prediction beyond close-copy lookup.

In ZEL031 / THP1, the model still helped when the held-out compounds used building-block identities withheld during training. It beat the nearest-neighbor baseline on most test compounds, which is the cleanest extrapolation result in the pilot.

FINDING 02

Simpler holdouts tell the same story.

When one building-block position was held out at a time, the same system continued to beat retrieval. That consistency makes the stricter result more credible.

FINDING 03

A dense library gives a different, still useful answer.

ZEL024 / HEK293 is so densely sampled that many held-out compounds still have very close analogs in the training set. That makes it excellent for filling gaps inside an explored design space, but it should not be marketed as the same kind of extrapolation.

FINDING 04

Holding out chemical neighborhoods is supportive.

When entire chemical neighborhoods were held out within a library, the model still beat retrieval in the main systems. That supports the idea that the model is learning signal beyond local analog copying.

FINDING 05

The hardest scaffold-hop question is not solved yet.

Cross-library scaffold-family transfer was weak retrospectively. That is not a failure of the story; it is a useful boundary. The paper defines a clean prospective chip run that can answer this hardest question directly.

What this enables

Trust comes from knowing the boundary.

A chemistry-to-phenotype model is valuable only if it helps when the next chemistry is different. This ladder shows where the current pilot already helps, where it is mainly doing useful gap-filling, and where the next experiment must be run. That makes the platform story more credible, not less: the benchmark tells the next chip exactly what to prove.
